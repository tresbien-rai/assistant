Trait picker (PT-03 reference)

The design chosen in PT-03 (PERSONA_TRAITS_DESIGN.md D9): tags and a searchable picker, with each section's prompt text shown underneath. Throwaway prototype with the real trait library; nothing is saved.

Tap + Add trait to browse or search. Each section's Prompt text is exactly what the model gets for that section. Click any sentence (or its tag) to edit it: that makes it customised, and Reset brings back the library text. Your own words go in the box underneath, as their own paragraph.
